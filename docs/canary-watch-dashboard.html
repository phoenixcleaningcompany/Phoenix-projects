What each verdict means

The decision

🟢 Green

The model works. Greenlight the workwear replication — still tranche-by-tranche and phased. Keep watching.

🟠 Amber

The idea works, one family is weak. The segmented sitemaps name it. Fix that pattern's uniqueness on the cleaning site, re-test, then replicate only the proven families.

🔴 Red

The pattern is rejected. Don't touch workwear with it. Rebuild the cleaning model first — more per-page uniqueness, prune/consolidate. Learned cheaply on one domain.
